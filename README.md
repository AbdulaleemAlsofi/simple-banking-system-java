# Simple Banking System Using Java

## Project Overview
An academic software project developed using Java as part of the Object-Oriented Programming course during the second academic level of the Information Technology program.

The project aims to simulate basic banking operations through a simple application that allows users to check their account balance, deposit money, and withdraw money.

## Project Objectives
- Apply object-oriented programming concepts using Java.
- Understand how account data and balances are organized and managed.
- Gain practical experience in developing applications that simulate real-world scenarios.
- Learn how to implement basic banking operations.
- Understand how account balances are updated based on transactions.

## Features
- **Balance Inquiry:** Check the current account balance.
- **Deposit:** Add money to the account balance.
- **Withdrawal:** Deduct money from the account balance.
- **Balance Management:** Update the account balance based on completed transactions.
- **Object-Oriented Programming:** Apply Java OOP concepts to organize account data and operations.

## Technologies Used
- **Programming Language:** Java
- **Development Environment:** Apache NetBeans IDE
